# Verified results

These files were generated by the deterministic offline command:

```bash
python run_signal_demo.py --output-dir results --seed 42
```

The demo combines lagged synthetic carry and trend signals across eight simulated commodities, applies unit gross exposure and 10 bps one-way transaction costs, and compares the result with an equal-weight synthetic benchmark.

Recorded result (238 monthly observations):

- Strategy annualized return: 4.68%
- Annualized volatility: 10.52%
- Zero-rate Sharpe: 0.445
- Maximum drawdown: -20.43%
- Equal-weight benchmark annualized return: 3.06%
- Equal-weight benchmark Sharpe: 0.350

Artifacts:

- `synthetic_carry_trend_metrics.json` - metrics, assumptions, seed, and claim boundary
- `synthetic_carry_trend_returns.csv` - monthly strategy and benchmark returns
- `synthetic_carry_trend_weights.csv` - lagged portfolio weights
- `synthetic_carry_trend_backtest.png` - cumulative performance chart

These are synthetic software-execution results, not a historical commodity backtest and not evidence of investable alpha. The six teaching notebooks fetch live public data and their outputs can vary by run date.
